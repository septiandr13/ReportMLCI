# ReportMLCI Backend API Documentation

## Overview
The ReportMLCI Backend API is built with ASP.NET Core 8 and provides RESTful endpoints for managing report clauses, their details, and sub-details. This documentation is designed to help frontend developers (particularly Angular developers) understand the API endpoints, request/response formats, and data models.

**Base URL:** `http://localhost:5000/api` (adjust port as per your configuration)

## Data Models

### 1. MasterClause
Represents the main clause master data.

```typescript
interface MasterClause {
  id: string;              // UUID (Guid)
  clauseCode: string;      // Max 50 characters
  clauseTitle: string;     // Max 200 characters
  clauseContent: string;   // nvarchar(max) - can be very long
  isActive: boolean;       // Default: true
  createdAt: Date;         // Auto-generated GETDATE()
  updatedAt: Date;         // Auto-generated GETDATE()
  masterClausesDetails?: MasterClausesDetails[];  // Navigation property
}
```

**Database Table:** `MasterClauses`
- Primary Key: `Id` (GUID, generated by `NEWID()`)
- Indexes: Standard primary key index

---

### 2. MasterClausesDetails
Represents sub-clauses under a main clause (one-to-many relationship with MasterClause).

```typescript
interface MasterClausesDetails {
  id: string;              // UUID (Guid)
  masterClauseId: string;  // Foreign Key to MasterClause
  clauseSubCode: string;   // Max 50 characters
  clauseSubTitle: string;  // Max 200 characters
  clauseSubContent: string;// nvarchar(max)
  isActive: boolean;       // Default: true
  createdAt: Date;         // Auto-generated GETDATE()
  updatedAt: Date;         // Auto-generated GETDATE()
}
```

**Database Table:** `MasterClausesDetails`
- Primary Key: `Id` (GUID, generated by `NEWID()`)
- Foreign Key: `MasterClauseId` ? `MasterClauses.Id` (OnDelete: Cascade)
- Indexes: Primary key index, Foreign key index

---

### 3. MasterClausesSubDetails
Represents sub-details under a clause detail (one-to-many relationship with MasterClausesDetails).

```typescript
interface MasterClausesSubDetails {
  id: string;              // UUID (Guid)
  masterClauseDetailId: string;  // Foreign Key to MasterClausesDetails
  subDetailCode: string;   // Max 10 characters
  subDetailTitle: string;  // Max 200 characters
  subDetailContent: string;// nvarchar(max)
  isActive: boolean;       // Default: true
}
```

**Database Table:** `MasterClausesSubDetails`
- Primary Key: `Id` (GUID, generated by `NEWID()`)
- Foreign Key: `MasterClauseDetailId` ? `MasterClausesDetails.Id` (OnDelete: Cascade)
- Indexes: Primary key index, Foreign key index

---

### 4. MasterHeaderClause
Represents header/category information for clauses.

```typescript
interface MasterHeaderClause {
  id: string;                     // UUID (Guid)
  clauseHeaderCode: string;       // Max 50 characters
  clauseHeaderTitle: string;      // Max 200 characters
  clauseHeaderDescription: string;// nvarchar(max)
  isActive: boolean;              // Default: true
  createdAt: Date;                // Auto-generated GETDATE()
  updatedAt: Date;                // Auto-generated GETDATE()
  masterClauses?: MasterClause[]; // Navigation property
}
```

**Database Table:** `MasterHeaderClauses`
- Primary Key: `Id` (GUID, generated by `NEWID()`)
- Indexes: Standard primary key index

**201 Created:**
- Returns the created resource with a `Location` header pointing to the new resource

**204 No Content:**
- Returns empty response body for successful PUT and DELETE operations

---

### Error Responses

**400 Bad Request:**
```
Status: 400 Bad Request
Body: No content (or error details if available)
```
Possible causes:
- ID mismatch between URL and request body
- Invalid request format
- Validation errors

**404 Not Found:**
```
Status: 404 Not Found
Body: null
```
Possible causes:
- Requested resource does not exist
- Resource was deleted by another user

**500 Internal Server Error:**
```
Status: 500 Internal Server Error
Body: Error details (varies)
```
Possible causes:
- Database connection issues
- Unhandled exceptions
- Concurrency conflicts (DbUpdateConcurrencyException)

## Error Handling

### Common Error Scenarios

1. **Concurrency Conflict on Update**
   - Error: `DbUpdateConcurrencyException`
   - HTTP Status: `500 Internal Server Error`
   - Cause: Another user updated the resource between your read and write operations
   - Solution: Reload the resource and retry the update

2. **Foreign Key Violation**
   - Error: `DbUpdateException`
   - HTTP Status: `500 Internal Server Error`
   - Cause: Referenced parent record doesn't exist or violates constraints
   - Solution: Ensure referenced IDs exist before creating/updating

3. **Resource Not Found**
   - Error: `null` response
   - HTTP Status: `404 Not Found`
   - Cause: Resource with given ID doesn't exist
   - Solution: Check the ID and verify the resource was created

## Usage Examples

### Angular HTTP Service Example

```typescript
// master-clause.service.ts
import { Injectable } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Observable } from 'rxjs';

export interface MasterClause {
  id: string;
  clauseCode: string;
  clauseTitle: string;
  clauseContent: string;
  isActive: boolean;
  createdAt: Date;
  updatedAt: Date;
}

@Injectable({
  providedIn: 'root'
})
export class MasterClauseService {
  private apiUrl = 'http://localhost:5000/api/masterclause';

  constructor(private http: HttpClient) { }

  // Get all master clauses
  getAll(): Observable<MasterClause[]> {
    return this.http.get<MasterClause[]>(this.apiUrl);
  }

  // Get single master clause
  getById(id: string): Observable<MasterClause> {
    return this.http.get<MasterClause>(`${this.apiUrl}/${id}`);
  }

  // Create master clause
  create(clause: MasterClause): Observable<MasterClause> {
    return this.http.post<MasterClause>(this.apiUrl, clause);
  }

  // Update master clause
  update(id: string, clause: MasterClause): Observable<void> {
    return this.http.put<void>(`${this.apiUrl}/${id}`, clause);
  }

  // Delete master clause
  delete(id: string): Observable<void> {
    return this.http.delete<void>(`${this.apiUrl}/${id}`);
  }
}
```

### Component Usage Example

```typescript
// master-clause.component.ts
import { Component, OnInit } from '@angular/core';
import { MasterClauseService, MasterClause } from './master-clause.service';

@Component({
  selector: 'app-master-clause',
  templateUrl: './master-clause.component.html'
})
export class MasterClauseComponent implements OnInit {
  clauses: MasterClause[] = [];
  loading = false;
  error: string | null = null;

  constructor(private clauseService: MasterClauseService) { }

  ngOnInit() {
    this.loadClauses();
  }

  loadClauses() {
    this.loading = true;
    this.error = null;
    this.clauseService.getAll().subscribe({
      next: (data) => {
        this.clauses = data;
        this.loading = false;
      },
      error: (err) => {
        this.error = 'Failed to load clauses';
        this.loading = false;
        console.error(err);
      }
    });
  }

  createClause(clause: MasterClause) {
    this.clauseService.create(clause).subscribe({
      next: (created) => {
        this.clauses.push(created);
        alert('Clause created successfully');
      },
      error: (err) => {
        this.error = 'Failed to create clause';
        console.error(err);
      }
    });
  }

  updateClause(id: string, clause: MasterClause) {
    this.clauseService.update(id, clause).subscribe({
      next: () => {
        const index = this.clauses.findIndex(c => c.id === id);
        if (index > -1) {
          this.clauses[index] = clause;
        }
        alert('Clause updated successfully');
      },
      error: (err) => {
        this.error = 'Failed to update clause';
        console.error(err);
      }
    });
  }

  deleteClause(id: string) {
    if (confirm('Are you sure?')) {
      this.clauseService.delete(id).subscribe({
        next: () => {
          this.clauses = this.clauses.filter(c => c.id !== id);
          alert('Clause deleted successfully');
        },
        error: (err) => {
          this.error = 'Failed to delete clause';
          console.error(err);
        }
      });
    }
  }
}
```

To allow Angular frontend running on different port to access the API, add CORS to `Program.cs`:

```csharp
builder.Services.AddCors(options =>
{
    options.AddPolicy("AllowAngular", builder =>
    {
        builder.WithOrigins("http://localhost:4200")
               .AllowAnyMethod()
               .AllowAnyHeader();
    });
});

app.UseCors("AllowAngular");
```

## Additional Notes

### Date/Time Format
All dates in API responses are in ISO 8601 format (UTC): `YYYY-MM-DDTHH:mm:ssZ`

### ID Format
All IDs are GUIDs (Universally Unique Identifiers). When creating new records, the backend generates these automatically. Do not provide IDs when creating new records.

### HTTP Methods Summary
| Method | Purpose | Returns |
|--------|---------|---------|
| GET    | Retrieve data | 200 OK or 404 Not Found |
| POST   | Create data | 201 Created |
| PUT    | Update data | 204 No Content or 400/404 errors |
| DELETE | Delete data | 204 No Content or 404 Not Found |

## Support & Troubleshooting

### API not responding
1. Verify the backend is running
2. Check the correct port (default: 5000)
3. Check network connectivity
4. Review firewall settings

### Database connection errors
1. Verify SQL Server LocalDB is running
2. Check connection string in appsettings.json
3. Ensure database `ReportMLCI` exists
4. Run migrations if needed

### CORS errors in Angular
1. Verify CORS policy is configured on backend
2. Check the allowed origin matches your Angular app URL
3. Restart the backend API after configuration changes
